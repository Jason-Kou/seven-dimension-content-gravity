# AI 日报 A/B 实验（2026-10-18）

实验使用完全相同的 6 条新闻、10 个来源和 6 张图片，只改变写法。

- A：标准日报，独立编辑评分 33/40。
- B：七维引力版，主维度为独特角度、读者收益、作者声音、具体细节，评分 38/40。
- B 把六条新闻组织成六本账：协作账、运行账、安全账、实施账、资本账、流程账。
- B 的代价：长度增加约 16.9%，自然度略低。

结论不是“以后每天都写 B”。普通新闻日可以保留 A 的简洁，只强化导语和观察；当新闻存在共同主线时，再使用 B 的专题结构。

这个实验说明，七维引力的价值在于帮助编辑做选择，而不是把七项全部塞进一篇文章。
