# 七维内容引力模型

## 七个维度

| Dimension | 中文 | 核心问题 |
|---|---|---|
| `emotional_tension` | 情绪张力 | 读者为什么现在停下来？ |
| `reader_benefit` | 读者收益 | 读完后能理解、判断或行动什么？ |
| `story_or_case` | 故事／案例 | 是否有人物、场景、冲突、实验或过程？ |
| `unique_angle` | 独特角度 | 这篇内容提供了什么不同的解释框架？ |
| `author_voice` | 作者声音 | 为什么这篇文章应该由这个作者来写？ |
| `format_expression` | 表达形式 | 当前载体是否最适合这组信息？ |
| `specificity` | 具体细节 | 是否有数字、时间、对象、来源和限制？ |

## 使用规则

1. 先判断文章类型，再选择 2–4 个主维度。
2. 未选择的维度仍可作为辅助观察，但不能反过来绑架文章。
3. 情绪、故事和形式不适用时可以不使用，并说明原因。
4. 事实边界、中心判断、保密与版权边界始终是基础硬要求。
5. 修改后源文件哈希变化，旧审查必须失效并重新执行。

## 推荐配置

- 日报：独特角度、读者收益、作者声音、具体细节
- 深度报道：独特角度、具体细节、读者收益、故事／案例
- 产品内容：读者收益、具体细节、表达形式
- 案例复盘：故事／案例、具体细节、读者收益、作者声音
- 观点文章：独特角度、作者声音、情绪张力

## 不应该做的事

- 不为凑齐七项强塞煽情、故事或个人经历。
- 不用传播性掩盖事实错误、证据不足或利益冲突。
- 不把关键词计数当成质量结论。
- 不把改长等同于改好。
- 不让每篇文章都长成同一个模板。
